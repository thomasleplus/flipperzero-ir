# Dreo Nomad One (DOTF07)

A captured Flipper Zero infrared profile for the Dreo Nomad One tower fan
(model DOTF07).

- `Dreo_Nomad_One_DOTF07.ir` — the IR signal database; copy it to the Flipper
  Zero and open it in the **Infrared** app to control the fan.
- `config.json` — metadata describing the capture (device/model).
